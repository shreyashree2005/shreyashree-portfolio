# Shreyashree C R — Portfolio Website

## Files
- `index.html` — page content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation and footer year
- `assets/resume.pdf` — your resume

## Before publishing
1. Add your professional photo to `assets/` and name it exactly `profile.jpg`.
2. In `index.html`, replace the generic GitHub and LinkedIn URLs with your actual profile URLs.
3. Replace each project link (`https://github.com/`) with the correct repository URL, or remove the link if that project is not public.
4. Check the contact email and all resume details.

## Preview locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Create a new public GitHub repository, for example `shreyashree-portfolio`.
2. Upload the contents of this folder to the repository root (the `index.html` file must be at the top level).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The site URL will appear in the Pages settings, usually:
   `https://YOUR-GITHUB-USERNAME.github.io/shreyashree-portfolio/`

The public URL is not active until you publish the repository and GitHub Pages finishes deploying.
